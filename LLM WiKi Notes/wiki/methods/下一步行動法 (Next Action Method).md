# 下一步行動法 (Next Action Method)

## 1. 原理與心智機制

**下一步行動法 (Next Action Method)** 是 David Allen 在 GTD 體系中最具革命性的工具。
它的基本論點是：**「人類大腦無法執行一個『專案』或一個『模糊概念』，大腦只能執行『可見的物理動作』。」**

* **拖延的語言學陷阱**：
  當你在行事曆或待辦清單寫下「準備總體經濟學期中考」或「做專題簡報」時，大腦看到的是一座龐大、邊界未知的迷宮，前額葉會將其判定為威脅與高能耗任務，直接觸發邊緣系統的逃避反應。
* **物理動作定義 (Physical Action Test)**：
  如果一項行動不能拿著攝影機拍出動作，它就不是下一步行動！

## 2. 模糊任務 vs 具體物理行動對照表

| 模糊抽象的待辦項目（必死無疑） | 轉換後的「下一步物理行動」（立即啟動） |
| :--- | :--- |
| 「寫期末書面報告」 | 「打開 Chrome，進入國家圖書館論文網，輸入關鍵字『碳足跡』下載 2 篇 PDF」 |
| 「複習微積分第三章」 | 「拿出活頁紙與黑筆，手算課本 3.2 節範例第一題」 |
| 「找教授討論專題題目」 | 「打開 Gmail，寫一封 3 句話的信詢問教授週四辦公室時間 (Office Hour)」 |
| 「整理下學期選課」 | 「登入學校教務處選課系統，把通識課時間表截圖貼在桌面」 |

## 3. 三步提問轉換 SOP

當你發現自己正對著清單上的某件事拖延、心生畏懼時，立刻對自己問這三個問題：

1. **「這件事的終點長什麼樣子？」（釐清交付物）**
   * 例：一份 5 頁探討電商商業模式的 Word 檔案。
2. **「要走向這個終點，我身體必須做的『下一個物理動作』是什麼？」**
   * 手指該點擊哪裡？眼睛該看哪裡？身體該走向哪裡？
3. **「這個動作能在 3 分鐘內完成嗎？」**
   * 若能，立即搭配 [[兩分鐘定律 (Two-Minute Rule)]] 執行；若不能，再將該動作切碎至 3 分鐘可完成的微動作。
