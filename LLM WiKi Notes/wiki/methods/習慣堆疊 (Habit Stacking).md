# 習慣堆疊 (Habit Stacking)

## 1. 原理與神經突觸修剪機制

**習慣堆疊 (Habit Stacking)** 源於 BJ Fogg 的微習慣研究與 James Clear 的《原子習慣》。
它的神經學本質是利用大腦中已經高度穩固、自動化的「既有神經突觸網絡 (Existing Neural Pathway)」，作為新習慣的天然「觸發提示 (Cue)」。

* **為什麼孤立設定新習慣容易失敗？**
  若你對自己說「我每天要花 1 小時讀書」，因為沒有綁定明確的時間、空間與生活觸發點，大腦前額葉需要額外消耗意志力去辨識「何時該開始」，這往往直接引發 [[雙曲貼現 (Hyperbolic Discounting)]] 與拖延。
* **堆疊公式**：
  $$\text{「在［既有習慣］之後，我會執行［新習慣］」}$$

## 2. 大學生痛點的實戰堆疊配方

大學生的校園作息看似不規律，但依然存在許多固定發生的生理與生活錨點：

| 既有穩定舊習慣（錨點） | 堆疊的抗拖延微動作（新習慣） | 解決的痛點 |
| :--- | :--- | :--- |
| **「晚餐一吃完」** | 「立刻坐在書桌前打開筆記本，寫下一行字」 | 解決飯後無意識躺平滑手機到深夜 |
| **「走出浴室吹完頭髮」** | 「把手機放到客廳充電，拿出紙本讀 5 頁」 | 杜絕睡前躺在床上刷短影音引發的報復性熬夜 |
| **「走進圖書館坐下」** | 「戴上降噪耳機，倒滿一杯溫水，開啟工作區」 | 建立進入 [[深度工作 vs 淺薄工作 (Deep Work vs Shallow Work)]] 的啟動儀式 |
| **「早上關掉鬧鐘下床後」** | 「在便條紙寫下今天 3 個 [[下一步行動法 (Next Action Method)]]」 | 消除晨間茫然無措的啟動阻力 |

## 3. 防呆設計：堆疊的兩大鐵律

1. **時間顆粒極小化**：
   * 剛堆疊的新習慣必須符合 [[兩分鐘定律 (Two-Minute Rule)]]。不能堆疊「晚餐一吃完我就讀微積分 3 小時」，這會引發大腦強烈抗拒；必須是「晚餐一吃完我就打開課本翻到練習題」。
2. **觸發提示必須高度具體**：
   * 錯誤提示：「有空的時候我就看講義」。
   * 正確提示：「當我把咖啡杯放在桌上的那一刻，我就打開 PDF 檔案」。
