# 艾森豪矩陣 (Eisenhower Matrix)

## 1. 原理與四象限劃分

**艾森豪矩陣 (Eisenhower Matrix)** 又稱四象限法則，由美國前總統 Dwight D. Eisenhower 提出、後經 Stephen Covey 在《與成功有約》中普及。
其核心名言是：**「緊急的事往往不重要，重要的事往往不緊急。」**

```
               緊急 (Urgent)             不緊急 (Not Urgent)
          ┌─────────────────────────┬─────────────────────────┐
重要      │   【第 I 象限】立即處理    │   【第 II 象限】計畫執行  │
(Important)│  危機、死線邊緣的期末報告   │ 期末專案規劃、深度自學、運動│
          ├─────────────────────────┼─────────────────────────┤
不重要    │   【第 III 象限】委派/快決 │   【第 IV 象限】直接剔除  │
(Not Imp.)│ 填收據、回覆例行通知郵件  │ 無目的刷短影音、過度沉溺娛樂│
          └─────────────────────────┴─────────────────────────┘
```

## 2. 大學生與小資族專屬場景解析

| 象限分類 | 處置策略 | 大學生 / 小資族典型場景 | 常見心智陷阱 |
| :--- | :--- | :--- | :--- |
| **第 I 象限：重要且緊急** | **立即處理 (Do)** | 明天要交的期末報告、當天截止的選課、突發身體不適。 | 永遠陷在「救火隊」模式，導致前額葉皮質長期高壓耗損。 |
| **第 II 象限：重要不緊急** | **計畫執行 (Decide)** | 提早進行的專案規劃、英語證照學習、定期運動、人脈經營。 | 最容易被拖延！因缺乏外部死線而受 [[雙曲貼現 (Hyperbolic Discounting)]] 稀釋。 |
| **第 III 象限：不重要但緊急** | **委派/快速解決 (Delegate/Batch)** | 填寫系學會報帳收據、回覆瑣碎社群群組訊息、幫室友代購。 | 常被誤認為「工作很認真」的假性勤奮（[[深度工作 vs 淺薄工作 (Deep Work vs Shallow Work)]]）。 |
| **第 IV 象限：不重要不緊急** | **直接剔除 (Delete)** | 無目的滑 TikTok / IG Reels、點開第 4 集 YouTube 自動推薦影片。 | 當大腦感到焦慮時，邊緣系統本能尋求多巴胺逃避的終極黑洞。 |

## 3. 與實戰工具的聯動 SOP

1. **結合 1-3-5 法則**：
   * 第 I 象限的任務 $\rightarrow$ 優先進入 [[1-3-5 待辦法則 (1-3-5 Rule)]] 的「1 個大任務」或「中型任務」。
   * 第 II 象限的任務 $\rightarrow$ **必須強制預約專屬時間**，利用 [[時間塊排程 (Time Blocking)]] 鎖定。
   * 第 III 象限的任務 $\rightarrow$ 運用 [[兩分鐘定律 (Two-Minute Rule)]] 快速消滅，或在淺薄事務塊批次處理。
   * 第 IV 象限的任務 $\rightarrow$ 透過 [[環境摩擦力工程 (Friction Engineering)]] 物理屏蔽。
