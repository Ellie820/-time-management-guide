# 完美主義癱瘓 (Perfectionism Paralysis)

## 1. 定義與心理學機制

**完美主義癱瘓 (Perfectionism Paralysis)** 指個體因為對自身產出抱持過高的期待、極度恐懼未達標準帶來的負面評價，導致在任務開始前產生強烈的認知與情緒阻力，最終採取「逃避開始（拖延）」或「陷入細節強迫（假性勤奮）」的心理癱瘓狀態。

* **核心心理公式**：
  $$\text{自我價值 (Self-Worth)} = \text{個人能力 (Ability)} = \text{具體表現 (Performance)}$$
* **潛意識防衛機制 (Psychological Defense)**：
  如果我竭盡全力但產出平庸，我的自我價值將徹底崩塌；
  但如果我拖到最後一晚才趕出來，即使成果不佳，我也可以自我安慰：「*這不是我智商或能力的問題，純粹是我沒時間做而已。*」
  拖延因此成為保護脆弱自尊的護盾。

---

## 2. 大學生的常見表現 (Symptom Check)

* **白紙恐懼 (Blank Page Syndrome)**：盯著 Word 或 Google Docs 的空白畫面超過 2 小時，連標題和第一段都改了 10 次依舊不滿意，最後乾脆切去滑手機。
* **資料收集成癮 (Research Trap / Shallow Work)**：號稱在做研究，下載了 50 篇 PDF、看了數十個 YouTube 教學，卻遲遲不肯動手寫下自己的第一行文字。這是一種隱蔽的 [[淺薄工作 vs 深度工作 (Deep Work vs Shallow Work)]]。
* **全有全無思維 (All-or-Nothing Thinking)**：「如果我不能一口氣專注 3 個小時，那我現在有 20 分鐘的空檔就先別開始了。」

## 3. 破解完美主義的臨床處方

1. **粗製濫造許可證 (License to Create a Shitty First Draft)**：
   * 允許第一版是徹底的垃圾。完成比完美重要十倍。
   * 文學家海明威說過：「任何作品的第一版都是狗屎。」
2. **啟動微阻力法**：
   * 使用 [[兩分鐘定律 (Two-Minute Rule)]]，目標不是「寫好引言」，而是「隨意打出 3 句完全不需要通順的話」。
3. **客觀解離 (Cognitive Defusion)**：
   * 告訴自己：「這份作業只代表我『此刻對這門課的理解程度』，既不能定義我未來的成敗，也不能衡量我作為一個人的本質價值。」
