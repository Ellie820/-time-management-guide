# 習慣迴路 (Habit Loop)

## 1. 定義與四階段模型

大腦是一台追求「能量消耗最小化」的模式辨識機器。**習慣迴路 (Habit Loop)** 描述了神經系統將複雜行為自動化固化的四步循環（基於神經科學家與 James Clear 的行為架構）：

```
提示 (Cue) ──> 渴望 (Craving) ──> 回應 (Response) ──> 獎賞 (Reward)
   ^                                                       │
   └───────────────────────────────────────────────────────┘
```

1. **提示 (Cue)**：觸發行為的內外在信號（時間、地點、情緒、前置動作）。大腦預測即將獲得獎賞。
2. **渴望 (Craving)**：多巴胺激發的驅動力。你渴望的並非點擊螢幕這個動作，而是渴望「解除無聊」或「逃避壓力」的心理狀態轉變。
3. **回應 (Response)**：你實際執行的動作（滑手機、吃零食、打開課本）。是否能夠被執行取決於**摩擦力大小**與個體當下擁有的心智能力。
4. **獎賞 (Reward)**：大腦神經元確認「這個行為能帶來放鬆/快感」，並在大腦基底核 (Basal Ganglia) 強化神經迴路，使該迴路在下一次遇到類似提示時更迅速被喚醒。

## 2. 大學生的惡性習慣迴路解析

* **情境**：期末考前壓力大、坐在書桌前不知所措。
  * **提示**：打開複雜的投影片，感到大腦疲累與焦慮。
  * **渴望**：渴望迅速擺脫被無力感壓迫的痛苦狀態。
  * **回應**：手指下意識點開手機上的社群媒體或遊戲（極低阻力）。
  * **獎賞**：即時獲得短暫的多巴胺刺激，焦慮被暫時麻痺。
  * **後果**：大腦學會了「只要一感到課業壓力，最快解除痛苦的方法就是拿起手機」，形成了牢固的拖延成癮迴路。

## 3. 駭入習慣迴路的重塑法規

不能消滅習慣，只能「替換迴路」或「操縱阻力」：

| 階段 | 破除拖延壞習慣 | 建立高效專注好習慣 |
| :--- | :--- | :--- |
| **提示 (Cue)** | 讓提示隱而不見：收起手機、清除書桌雜物 | 讓提示顯而易見：前一晚把筆記開好在螢幕中央 |
| **渴望 (Craving)** | 讓誘惑缺乏吸引力：算清拖延帶來的高昂代價 | 讓行動具吸引力：誘惑綑綁（讀完 25 分鐘喝美味飲品） |
| **回應 (Response)** | 讓行動困難重重：增加物理摩擦（密碼複雜化、手機放客廳） | 讓行動輕而易舉：實施 [[兩分鐘定律 (Two-Minute Rule)]] |
| **獎賞 (Reward)** | 讓後果令人不適：與朋友建立對賭承諾協議 | 讓獎賞即時滿足：在 [[非排程表 (The Unschedule)]] 上劃掉任務 |
