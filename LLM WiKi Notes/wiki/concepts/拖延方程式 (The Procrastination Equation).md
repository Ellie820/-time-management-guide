# 拖延方程式 (The Procrastination Equation)

## 1. 統一動機數學模型

卡爾加里大學教授 Piers Steel 整合了心理學、認知科學與行為經濟學中長達數十年的研究，提煉出了計算人類當前行動意願的公式：

$$\text{動機強度 (Motivation)} = \frac{\text{期望 (Expectancy)} \times \text{價值 (Value)}}{\text{衝動性 (Impulsiveness)} \times \text{延遲 (Delay)}}$$

* **分子（正向推動力）**：
  * **期望 (Expectancy)**：你對「自己能否把這件事做成」的自信度。期望低 $\rightarrow$ 害怕失敗、[[完美主義癱瘓 (Perfectionism Paralysis)]]、不想動筆。
  * **價值 (Value)**：這件事對你而言的趣味、意義或獎賞豐厚度。價值低 $\rightarrow$ 枯燥無聊、提不起勁。
* **分母（負向阻礙力）**：
  * **衝動性 (Impulsiveness)**：你對周圍環境誘惑（即時多巴胺）的敏感與易分心程度。衝動性高 $\rightarrow$ 頻繁受 [[注意力殘留 (Attention Residue)]] 摧殘。
  * **延遲 (Delay)**：從現在到成果交付/死線的距離。延遲長 $\rightarrow$ 觸發嚴重的 [[雙曲貼現 (Hyperbolic Discounting)]]。

## 2. 大學生為什麼總是拖延？（公式診斷法）

拿大學生期末報告來代入公式：
1. **期望極低**：題目好難、文獻看不懂，深怕寫出來被教授批得一文不值。
2. **價值極低**：必修課理論又乾又硬，對現實求職看不到直接用處。
3. **衝動性極高**：手機就放在手邊，隨時有群組聊天、短影音通知、遊戲組隊邀約。
4. **延遲極長**：距離期末還有 3 週，時間看似很充裕。

**結果**：分子趨近於 0，分母被放大數十倍，動機強度幾近於零，拖延成為神經生物學上的必然結果！

## 3. 調控四大變數的抗拖延矩陣

| 調控變數 | 操作目標 | Wiki 實戰工具推薦 |
| :--- | :--- | :--- |
| **提升期望 (Expectancy)** | 降低認知難度，製造小贏螺旋 | [[兩分鐘定律 (Two-Minute Rule)]]、[[下一步行動法 (Next Action Method)]] |
| **提升價值 (Value)** | 綑綁喜好事物，重新賦予個人意義 | 誘惑綑綁（[[習慣迴路 (Habit Loop)]]） |
| **降低衝動性 (Impulsiveness)** | 物理阻斷干擾，降低意志力依賴 | [[環境摩擦力工程 (Friction Engineering)]]、[[時間塊排程 (Time Blocking)]] |
| **縮短延遲 (Delay)** | 人造微死線，消除遙遠的等待幻覺 | [[非排程表 (The Unschedule)]]、同行監督機制 |
